## 1. Important distinction: citations vs backlinks

A link from the Esmer site **to** an article is an outbound citation. A backlink is a link **from that third-party site back to Esmer's canonical domain**.

This repository can build the citation/source graph now. It cannot manufacture third-party backlinks. After launch, use the source list below to request legitimate link updates where an outlet, venue, profile, or past feature has an appropriate `Official Website`, artist bio, or source-link field.

Never buy spam backlinks, create fake profiles, mass-post comment links, or misrepresent affiliation.
